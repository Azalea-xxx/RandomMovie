# MoviePick (RandomMovie)

Веб-приложение для подбора фильмов по пользовательским критериям (жанр, год, рейтинг, страна, длительность) с возможностью случайного выбора и сохранения фильмов в избранное. Данные о фильмах получаются через внешний REST API [The Movie Database (TMDB)](https://www.themoviedb.org/documentation/api).

## Технологии

HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Animate.css, Font Awesome. Хранение избранного реализовано на стороне клиента через LocalStorage браузера, отдельного бэкенда у приложения нет.

## Запуск

Открыть `index.html` в браузере. Для полноценной работы поиска нужен собственный API-ключ TMDB.

## Аналитика и документация проекта

Полная аналитическая документация, а именно техническое задание (SRS), диаграммы в нотациях IDEF0, IDEF3, UML и BPMN, а также продуктовые метрики с рабочими SQL-запросами, находится в папке [`/docs`](./docs/README.md).

Кратко, что там есть:
- **Диаграммы** - функциональная модель (IDEF0), процессная модель (IDEF3), проектирование архитектуры (UML: use case, class, sequence, state machine), бизнес-процесс с участниками (BPMN)
- **[SRS.md](./docs/SRS.md)** -  функциональные и нефункциональные требования к системе по ГОСТ 34.602-2020
- **[metrics.md](./docs/metrics.md)** - продуктовые и технические метрики (conversion rate, RED-метрики надёжности API) с синтетическим набором данных и разобранными SQL-запросами
